DEEP DIVE: TECHNICAL PROBLEM SOLVING

Case 01. 유연한 구독 모델과 권한 제어

Authority Logic

[Problem] 구독 취소 즉시 권한을 회수하면 결제한 기간만큼의 서비스 이용 권리가 침해되는 UX 문제 발생
[Solution] '취소 예약' 상태인 cancelAtPeriodEnd 플래그와 subscriptionExpiresAt 타임스탬프를 조합하여 로직 설계
[Result] 로그인 시 만료 시간과 현재 서버 시간을 대조하여, 기간이 종료된 시점에만 등급을 자동 강등시키는 견고한 권한 시스템 구축

Case 02. NoSQL 데이터 구조 선제적 설계

Architecture Design

[Foresight] 초기 설계 단계에서 커뮤니티 피드 조회 시 발생하는 N+1 쿼리로 인한 Firebase 데이터 읽기(Read) 비용 증가와 네트워크 병목 현상 발생을 예측
[Action] Firebase Firestore의 과금 기준(읽기 횟수)과 NoSQL의 구조적 특성을 고려하여 기획 단계부터 비정규화(Denormalization) 기반의 데이터 모델을 설계함. likesCount와 commentsCount 등의 필드를 게시글 상위 문서에 병합 적용
[Outcome] 런칭 시점부터 추가 쿼리 없이 단 1회의 읽기만으로 게시글 렌더링을 구현하여 논리적 계산 기준 데이터 읽기(Read) 요청을 약 70~80% 절감하는 구조를 완성하고 클라이언트 로딩 속도를 유의미하게 개선
